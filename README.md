### 🚀 Featured projects

- **ApexFlow** · *Angular 19, Signals, RxJS, PrimeNG, Spring Boot 3, PostgreSQL*
  <br>A CRM and analytics dashboard, my Computer Engineering thesis, built during my internship at IPS. One reusable state class keeps page, sort and filters in the URL, so changing a filter fires exactly one API call and every table in the app shares the same logic. The demo has one-click accounts for an admin and a regular user.
  <br>[🔴 Live demo](https://dashboard-tesi.vercel.app/welcome) · [Frontend code](https://github.com/xdelmo/dashboard-tesi) · [Backend code](https://github.com/xdelmo/backend-tesi)

- **PokèVerba** · *WordPress, PHP, React, Vite*
  <br>A daily Pokémon crossword I build and run with a friend who writes the content. The app only knows how long each word is and the API checks whole words, so the answers never reach the browser and the Check button can't give letters away. Every clue is composed from PokéAPI facts and rejected if it names the answer.
  <br>[🧩 Play today's puzzle](https://sbustiamobro.it) · [Code](https://github.com/xdelmo/pokeverba-site)

- **Wedding 3D Invite** · *React, TypeScript, Three.js, Tailwind CSS*
  <br>Two friends wanted their paper wedding invitation, lace and pearls included, rebuilt for the phone. A Three.js envelope opens at a tap, then eleven slides cover the day, the maps, the dress code and the RSVP. The 3D scene stops rendering once the envelope is open, so reading the invite costs no battery.
  <br>[💌 Open the demo](https://wedding-3d-invite-demo-five.vercel.app/) · [Code](https://github.com/xdelmo/wedding-3d-invite)
